# Сообщения о проблемах

Не публикуйте в issues пароли, приватные SSH-ключи, ключи подписи обновлений, settings.json, известные ключи серверов или личные журналы. Даже очищенный отчёт может содержать IP и имена сетевых подключений.

Публичное описание ошибки должно содержать версию, общие шаги воспроизведения и обезличенное сообщение. О доступе к приватному каналу для сообщения об уязвимости договоритесь с владельцем репозитория отдельно; адрес контакта пока не задан.

Ключ подписи будущих обновлений нельзя хранить в исходниках или в артефактах сборки. Автоматическое обновление ещё не реализовано.
